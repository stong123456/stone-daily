# Stone Daily 独立网站商业化规划（暂缓）

状态：已存档，暂不进入产品开发。

## 核心原则

Stone Daily 作为独立网站完成获客、注册、订阅、交付与续费，不依附第三方内容或交易平台。基础行情、公共资讯与基础冷静工具继续免费；付费价值主要来自个性化、连续记录、主动提醒和节省时间，而不是喊单或收益承诺。

## 建议顺序

1. Free + Pro 会员：自选云同步、个性化早晚报、异动提醒、每周复盘、深度解读与历史记录。
2. 明确标注的克制型赞助位，与热点排名和 AI 结论隔离。
3. 工具箱返佣，优先安全、数据和效率工具，清楚披露佣金关系。
4. 深度报告点数包，作为 Pro 增购而非首发主产品。
5. 用户模式验证后，再直接销售社群、KOL 或企业授权版本。

## 暂定价格

- 创始 Pro：199 元/首年。
- 标准 Pro：29 元/月或 269 元/年，以年付为主。
- 正式收费前先验证账号、自选云同步、个性化日报和权益系统。

## 商业化前置条件

- 逐一确认所有交易所行情、Logo 和新闻源的商业展示及再分发授权。
- 根据实际运营主体完成虚拟资产信息、广告返佣、支付、隐私与投资信息合规审查。
- 建立用户、订阅、权益、使用记录、通知偏好和退款后台。
- 达到稳定回访和明确付费意愿后再开放收费。

恢复该规划时，应先完成数据商业授权清单，再开始会员支付开发。
